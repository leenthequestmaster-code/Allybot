# Katalog Simbol & Ornamen untuk Output Allybot

Katalog ini adalah **kurasi**, bukan salinan penuh dari situs sumber. Tujuannya adalah memberi bahan desain yang cukup luas untuk merapikan output command Allybot, sambil menjaga keterbacaan di WhatsApp. Koleksi sumber menampilkan divider dekoratif, symbol board, panah, bullet, frame, dan emoji yang bisa dicopy-paste.[1][2][3][4][5][6][7]

> **Arah visual Allybot:** roleplay dekoratif yang lembut, sedikit mystical, floral, dan fox-like; bukan layout minimalis generik, tetapi tetap mudah discan dalam chat. Gunakan maksimal satu header, satu divider utama, dua jenis bullet, dan satu footer per pesan panjang.

## 1. Legenda pemakaian

| Label | Arti | Penggunaan yang disarankan |
|---|---|---|
| **Core** | Ringkas dan relatif aman dibaca di banyak perangkat. | Layout default global. |
| **Expressive** | Lebih dekoratif, tetapi perlu preview di WhatsApp. | Menu, profil, reward, event, roleplay. |
| **Accent** | Simbol kecil untuk menandai satu informasi. | Status, field, pagination, error. |
| **Hindari sebagai default** | Terlalu padat, panjang, atau berisiko berbeda antarperangkat. | Hanya jika telah diuji pada perangkat komunitas. |

Gunakan satu pola untuk field dan pola lain untuk daftar agar struktur langsung terbaca.

## 12. Batas desain agar tetap terbaca

Karakter Unicode dan kombinasi dekoratif dapat tampil berbeda, atau bahkan menjadi kotak, tergantung font/perangkat.[5] Karena itu, hindari menjadikan glyph langka sebagai satu-satunya penyampai makna. Jangan gunakan lebih dari dua baris ornament sebelum isi. Hindari line art tinggi atau text art pada command yang dipanggil rutin. Jangan menyisipkan zero-width text, character combining berlebihan, atau font generator yang mengubah seluruh teks fungsional seperti ID grup, command, URL, angka, dan mention.

Untuk command yang memiliki mention clickable, teks `@nomor` tetap harus sederhana dan metadata mention WhatsApp tetap dikirim terpisah. Untuk command yang memiliki URL, link tetap harus berdiri sendiri agar mudah dibuka. Untuk ID grup dan data teknis, pakai monospace atau teks polos; jangan menggantinya dengan fancy font.
