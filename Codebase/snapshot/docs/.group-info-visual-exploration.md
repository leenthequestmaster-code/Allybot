# Eksplorasi Internal — Group Info Guild-Themed

Dokumen kerja ini menguji komposisi visual, bukan code atau desain final.

## Variasi A — Registry Rail

Menggunakan rail vertikal `╎` dan segmentasi Record/Authority/Chronicle. Kelebihan: sangat terbaca. Kekurangan: terasa terlalu seperti card/ledger generik dan kurang eksperimental.

## Variasi B — Official Registry Card

Menggunakan box `┌─/└─` untuk blok Registration/Officers/Note. Kelebihan: jelas. Kekurangan: terlalu tabel, terlalu formal, kurang punya gerak visual.

## Variasi C — Sigil & Census

Menggunakan emblem pembuka kecil, title highlight, nameplate grup, section census dengan angka dipasangkan, lalu authority dan chronicle. Kelebihan: hierarchy berbasis komposisi, bukan box; dapat terasa seperti halaman registry guild. Risiko: jangan menjadikan separator terlalu ornamental.

## Variasi D — Scroll Index

Menggunakan line art menyerupai gulungan dan daftar indeks. Kelebihan: kuat secara roleplay. Kekurangan: rawan terlalu ramai dan terasa medieval generic.

## Pilihan arah

Variasi C dipilih. Bahasa visual final harus menggunakan:

1. Emblem pembuka tunggal sebagai crest, bukan header penuh.
2. Judul `Group Info` dengan inline code highlight sebagai titik fokus.
3. Nameplate terpisah untuk nama grup.
4. Census sebagai satu pasangan angka, tidak empat field bernilai setara.
5. Authority sebagai dua entri ringkas untuk creator dan bot.
6. Chronicle berupa satu blockquote deskripsi.
7. Separator pendek sebagai ritme antara section, tidak menjadi border panjang.
8. Tidak memakai format Puzzle Quest seperti `#... — ...`, bullet floral tertentu, list reward, action row, atau motif separator yang sama.
